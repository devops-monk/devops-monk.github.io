Hey, I’m Abhay

I’m a DevOps Engineer with a passion for automation, cloud infrastructure, and building things that run reliably at scale. I started this blog to document my learning journey and share practical knowledge with the community — the kind of content I wish I had when I was starting out.

What I Work With

  • Cloud & Infrastructure — AWS, Terraform, and infrastructure as code
  • Containers & Orchestration — Kubernetes, Helm, Docker
  • CI/CD — GitHub Actions, Jenkins, ArgoCD
  • DNS & Networking — PowerDNS, Nginx, self-hosted services
  • Languages — Python, Node.js, Bash

Personal Projects

I enjoy building self-hosted tools that solve real problems. My current project is ddns.devops-monk.com — a fully self-hosted Dynamic DNS platform built with PowerDNS, Node.js, and React. It is open source and free to use.

Certifications

  • Certified Kubernetes Application Developer (CKAD)
